Generate a playable HLS URL for a Yanhekt recording.

Forces every playlist/segment fetch to go to Yanhekt instead of the edge cache. Slower; only useful for debugging.
Paste this into any HLS player (hls.js, Safari, VLC, ffmpeg).

The login token is embedded in the generated URL (so HLS players can fetch every segment). Treat the URL as a secret — anyone with it can stream as you until the token expires. Recorded videos only.
