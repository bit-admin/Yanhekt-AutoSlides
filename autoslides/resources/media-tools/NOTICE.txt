=============================

FFmpeg project: https://ffmpeg.org/
Licensing: https://ffmpeg.org/legal.html

The build is AutoSlides' own minimal configuration of FFmpeg 9.0.2 and
statically includes:
- x264 (GPL-2.0-or-later), Copyright (c) the x264 project.
  See x264-COPYING. https://www.videolan.org/developers/x264.html
- Opus (BSD-3-Clause), Copyright (c) Xiph.Org Foundation and contributors.
  See opus-COPYING. https://opus-codec.org/
- zlib (zlib licence; Windows and Linux builds), Copyright (c) Jean-loup
  Gailly and Mark Adler. See zlib-LICENSE. https://zlib.net/
  The macOS build uses the system zlib.

Corresponding Source: the exact source archives (FFmpeg, x264, Opus, zlib),
the build script and SHA-256 checksums of every file are published with the
binaries at
https://github.com/bit-admin/Yanhekt-AutoSlides/releases/tag/ffmpeg-9.0.2-r1
SOURCES.txt lists the archives with their checksums. The build script is
autoslides/scripts/ffmpeg-minimal/build.sh in the AutoSlides source tree.

The adjacent build-info.json records the build, download URL, archive SHA-256
pin and FFmpeg configuration output.
